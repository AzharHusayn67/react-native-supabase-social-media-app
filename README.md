# SocialNode — React Native Supabase Social Media App

A full-stack **React Native Expo social media app** powered by **Supabase**, with realtime chat, stories, posts, group chat, push notifications, media uploads, and **Agora audio/video calling**.

> **Not just a UI kit.** SocialNode includes the complete mobile app source code, Supabase backend setup, Row Level Security policies, Storage configuration, Realtime setup, Edge Functions, and buyer documentation.
